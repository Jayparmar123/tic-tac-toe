# 🎮 Tic-Tac-Toe Game (HTML, CSS, JavaScript)

A simple and elegant Tic-Tac-Toe game with a modern UI built using HTML, CSS, and JavaScript. Play against a friend with turn indicators, winning highlights, and a draw animation!

## 📸 Preview

👉 [Live Demo](https://Jayparmar123.github.io/tic-tac-toe/)

## 🚀 Features

- ❌ ⭕ Turn-based play  
- ✨ Smooth transitions and hover effects  
- 🟢 Highlights winning cells  
- 🤝 Detects and shows "Game Draw"  
- 🔁 One-click Reset Button  
- 📱 Responsive layout  

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox, Gradients, Transitions)  
- JavaScript (ES6)
